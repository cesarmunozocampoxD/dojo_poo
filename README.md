# POO — Dojo de Programación Orientada a Objetos

Repositorio de práctica y ejercicios de **Programación Orientada a Objetos (POO)** en Java. Aquí se van agregando ejercicios pequeños para reforzar conceptos como encapsulamiento, herencia, polimorfismo, interfaces y abstracción.

## Índice de ejercicios

| Ejercicio | Ubicación | Descripción | Conceptos clave |
|---|---|---|---|
| Calificaciones y Campeón | [EJERCICIOS/](EJERCICIOS/) | Clases básicas con atributos privados, constructor y getters/setters (`Calificaciones` calcula un promedio, `Campeon` es un ejemplo simple de encapsulamiento) | Encapsulamiento, constructores, getters/setters |
| Figura de ejemplo | [EJERCICIOS/FiguraEjemplo.java](EJERCICIOS/FiguraEjemplo.java) | Clase `FiguraEjemplo` con distintos constructores sobrecargados y métodos pendientes de implementar (`calculaPerimetro`, `calculaArea`) | Encapsulamiento, sobrecarga de constructores |
| Polimorfismo con animales | [poli1/](poli1/) | Jerarquía de animales (`Animal` abstracta, `Perro`, `Gato`, `Vaca`, `Pajaro`, `Pato`) con interfaces de capacidades (`ITerrestre`, `IVolador`, `IAcuatico`) | Herencia, clases abstractas, interfaces, polimorfismo |

> A medida que se agreguen nuevos ejercicios, se deben incluir en esta tabla con su ubicación y una breve descripción.
